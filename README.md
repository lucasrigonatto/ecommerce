# E-commerce Storefront

A responsive storefront interface built with HTML, CSS, and JavaScript.

## What problem did I work on?

I wanted to practice organizing a small online store into reusable page layouts: product discovery, a product detail page, editorial content, and a cart interface.

## What is included?

The repository contains home, shop, product, blog, about, contact, and cart pages, shared styles, image assets, and JavaScript for the mobile navigation.

## How can I check it?

Serve the repository with any static HTTP server:

```bash
python -m http.server 8080
```

Open http://localhost:8080. Check navigation between the seven pages, open and close the mobile menu at a narrow viewport, and inspect product cards and the product page.

These are manual review steps, not an automated test report. There is no package installation or build step.

## Scope and learning

This is a frontend learning project. It does not implement a backend, checkout, payments, real inventory, or persistent cart operations. The cart page represents the interface only.

The focus is semantic page structure, responsive CSS, consistent layout, and a small amount of DOM interaction.
